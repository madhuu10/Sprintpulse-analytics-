# Escalation Process

**Attendance**: a "high absenteeism risk" flag from the model triggers a
manager check-in within one week — never an automatic HR case. If the
pattern continues after two consecutive flagged periods, the manager loops
in HR for a formal conversation about support options (schedule
flexibility, workload review, leave options).

**Sprint performance**: a team landing "off track" (completion rate below
60%) two sprints in a row triggers a retro deep-dive with the engineering
lead present, not just the team. The focus is root cause (scope discipline,
QA capacity, staffing) — this process is explicitly not meant to be used
for individual performance reviews; sprint metrics are team-level signals,
not individual scorecards.

Both processes exist to catch problems early and route them to a
conversation, not to automate any disciplinary action.
